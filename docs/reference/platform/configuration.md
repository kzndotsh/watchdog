# Configuration reference

**What this is:** every environment variable Watchdog reads: what it does, its default, whether it is required, whether it is a secret and which entrypoint reads it.  
**What this is not:** a setup walkthrough ([`self-host`](../../how-to/self-host.md), [`local-dev`](../../how-to/local-dev.md)) or the Cap API keys, which live in the Settings vault.

Generated by `pnpm generate:env` from the env metadata in `packages/env/src` (each field's `.meta()` and `reference.ts`). Do not edit by hand: `pnpm check:env` fails when this file or `env.example` is stale. `env.production.example` is hand-maintained (it is the compose file's environment), and the same check fails when it lists a variable that is not below or omits one the app validates.

## How to read it

- **Required** means startup fails without it. `web` and `worker` validate the same schema, so both containers need every required variable, even one only the web app uses.
- **Secret** variables are written blank in `env.example` and must never be logged or committed.
- **Used by** names the entrypoint that reads the variable: `web` (the app and API), `worker`, `cli` (`wd`), `migrate` (the container's migrator), `site` (the marketing site) or `compose` (only `docker-compose.prod.yml` reads it).
- **Placeholders and short secrets are refused at startup.** `BETTER_AUTH_SECRET` and `WD_MASTER_VAULT_KEY` need at least 32 characters and may not be a known placeholder (`change-me...`, `secret`, `password`, ...); `S3_SECRET_KEY` may not be a placeholder, nor the development default when `NODE_ENV` is `production`. The error names the variable. Generate a value with `openssl rand -base64 32`.
- An empty value counts as unset.

## Database

| Variable | Description | Default | Required | Secret | Used by |
| --- | --- | --- | --- | --- | --- |
| `DATABASE_URL` | Postgres connection URL of the application role. The password in it is a secret. | none | yes | yes | web, worker, migrate |
| `DATABASE_URL_MIGRATE` | Connection URL migrations use, for a role that may create schemas and tables. Falls back to DATABASE_URL. | none | no | yes | migrate |

## Authentication

| Variable | Description | Default | Required | Secret | Used by |
| --- | --- | --- | --- | --- | --- |
| `BETTER_AUTH_SECRET` | Signs sessions and cookies. At least 32 characters; known placeholder values are refused. Changing it signs everyone out. | none | yes | yes | web |
| `BETTER_AUTH_URL` | The exact URL users type in the browser, with scheme and no trailing slash. Also the CORS origin of the object-store bucket. | `http://127.0.0.1:3000` | no | no | web |
| `BETTER_AUTH_ALLOW_SIGNUP` | Open public registration (anyone can sign up and create organizations). Leave 0 and create the first admin with the bootstrap command; restart web after changing it. | `false` | no | no | web |
| `BETTER_AUTH_TRUSTED_ORIGINS` | Extra origins that may call the app, comma-separated (parsed to a list). | `empty` | no | no | web |

## Email (SMTP)

| Variable | Description | Default | Required | Secret | Used by |
| --- | --- | --- | --- | --- | --- |
| `SMTP_HOST` | SMTP server for invitation mail. Mail is sent only when both SMTP_HOST and SMTP_FROM are set. | none | no | no | web |
| `SMTP_PORT` | SMTP port. Unset sends on 587 (STARTTLS); 465 uses implicit TLS. | none | no | no | web |
| `SMTP_USER` | SMTP username, when the server requires authentication. | none | no | no | web |
| `SMTP_PASS` | SMTP password, when the server requires authentication. | none | no | yes | web |
| `SMTP_FROM` | Sender address of invitation mail (an email address). | none | no | no | web |

## Object storage

| Variable | Description | Default | Required | Secret | Used by |
| --- | --- | --- | --- | --- | --- |
| `S3_ENDPOINT` | S3-compatible endpoint the server reads and writes Evidence through (SeaweedFS locally). Browsers also upload to it with presigned requests unless S3_PUBLIC_URL is set. | none | yes | no | web, worker |
| `S3_PUBLIC_URL` | URL browsers use for presigned Evidence uploads and downloads, when it differs from S3_ENDPOINT (a public HTTPS name for an internal store). Unset presigns against S3_ENDPOINT. | none | no | no | web |
| `S3_ACCESS_KEY` | Access key id of the object store. | none | yes | no | web, worker |
| `S3_SECRET_KEY` | Secret key of the object store. The development default is refused when NODE_ENV is production. | none | yes | yes | web, worker |
| `S3_BUCKET` | Evidence bucket name. | none | yes | no | web, worker |
| `S3_REGION` | Region used to sign object-store requests. | `us-east-1` | no | no | web, worker |

## Vault

| Variable | Description | Default | Required | Secret | Used by |
| --- | --- | --- | --- | --- | --- |
| `WD_MASTER_VAULT_KEY` | Master key that encrypts stored Cap credentials. At least 32 characters (base64 or hex of 32 bytes recommended); known placeholders are refused. Back it up: without it stored credentials cannot be read, and changing it makes them unreadable unless you rotate it with just vault-rekey (node vault-rekey.mjs in the container). | none | yes | yes | web, worker |

## Container and process

| Variable | Description | Default | Required | Secret | Used by |
| --- | --- | --- | --- | --- | --- |
| `WD_SKIP_MIGRATIONS` | 1, true, yes or on skips migrations at container start; 0, false, no, off or empty runs them. The web image runs them; the worker image sets 1. | `0 (web), 1 (worker image)` | no | no | migrate |
| `WD_MIGRATIONS_DIR` | Folder of migrations. The image sets /app/drizzle; only tests change it. | `packages/db/drizzle` | no | no | migrate |
| `WD_LOG_DIR` | Folder of the NDJSON log drain, for a read-only or non-writable app directory. The image sets /tmp/evlog; stdout carries the same events. | `the app's own log folder` | no | no | web, worker |
| `WD_CLIENT_DIR` | Folder of the built browser assets the production server serves. The web image sets /app/client. | `apps/web/dist/client` | no | no | web |
| `PORT` | Port the production web server listens on. | `3000` | no | no | web |
| `HOST` | Address the production web server binds. | `0.0.0.0` | no | no | web |
| `SKIP_ENV_VALIDATION` | 1 skips environment validation (lint and image builds without secrets). Never set it in a deployment. | none | no | no | web, worker |

## Compose (docker-compose.prod.yml)

| Variable | Description | Default | Required | Secret | Used by |
| --- | --- | --- | --- | --- | --- |
| `POSTGRES_DB` | Database name of the Postgres container. | `watchdog` | no | no | compose |
| `POSTGRES_USER` | Role of the Postgres container; the stack builds DATABASE_URL from it. | `watchdog` | no | no | compose |
| `POSTGRES_PASSWORD` | Password of that role. Letters and digits only: it is placed in a connection URL (openssl rand -hex 24). | none | yes | yes | compose |
| `WEB_BIND` | Host address the web port binds. Loopback by default: publish it through a TLS reverse proxy. | `127.0.0.1` | no | no | compose |
| `WEB_PORT` | Host port of the web container. | `3000` | no | no | compose |
| `S3_PUBLISH_PORT` | Loopback host port of the object store (for the reverse proxy). | `9100` | no | no | compose |
| `WATCHDOG_WEB_IMAGE` | Image name of the web service. | `watchdog-web:local` | no | no | compose |
| `WATCHDOG_WORKER_IMAGE` | Image name of the worker service. | `watchdog-worker:local` | no | no | compose |
