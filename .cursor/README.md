# `.cursor/`

An **allowlist, not a blanket ignore** ([`.gitignore`](../.gitignore)). Tracked here: [`hooks.json`](hooks.json) (Cursor hook registration), [`hooks/stop-gate.mjs`](hooks/stop-gate.mjs), [`hooks/run-node.sh`](hooks/run-node.sh), and this file. Everything else under `.cursor/` (`rules/`, `skills/`, `agents/`, `plans/`, `settings.json`) is local-only. Portable agent content lives in `AGENTS.md` and [`.agents/skills/`](../.agents/skills/).

The `stop` hook runs the validators for dirty paths (`pnpm check:docs:strict`, `pnpm check:agents:strict`, `pnpm validate:agents`, scoped oxlint) and reports findings at most twice per turn (`loop_limit: 2`). The same script also runs as Claude Code's `Stop` hook, registered in [`.claude/settings.json`](../.claude/settings.json) with `--client=claude` (it answers `decision: "block"` and stops re-prompting once `stop_hook_active` is set); `--client=cursor` in `hooks.json` selects the Cursor reply shape. It is not fail-closed and always prints valid JSON, so a hook bug never blocks the agent. Local git hooks and CI gates: [`docs/contributing/ci-gates.md`](../docs/contributing/ci-gates.md). The repo-root [`.mcp.json`](../.mcp.json) (read-only Postgres, Playwright and Better Auth docs MCP servers) is read by Claude Code; Cursor users copy its entries, see [`docs/how-to/local-dev.md`](../docs/how-to/local-dev.md).

**Cursor spawns hooks without the project's nix devshell**, so `node`/`pnpm` are missing from `PATH`. `run-node.sh` tries a global `node` first (e.g. `nix profile install nixpkgs#nodejs`), then falls back to `direnv exec` for the flake devshell's `node`.

Skills are deletable: if one only works around a platform limitation that has since gone away, delete it (`git log` is the archive). Skill frontmatter rules are enforced by [`scripts/validate-agents.mjs`](../scripts/validate-agents.mjs).
